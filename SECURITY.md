# Security policy

HadiJob (https://hadijob.com) is a static site: it has no accounts, no server-side code and stores no personal data. A CV you match is read in your own browser and never uploaded.

## Reporting a problem

Please report security problems **privately** through [GitHub's private vulnerability reporting](https://github.com/ilker-ekin/hadijob/security/advisories/new), not in a public issue. Reports in English or Turkish are welcome.

Useful details: what you found, the URL, and the steps to reproduce it. You'll get an answer within a few days.

## In scope

- The site at hadijob.com and www.hadijob.com
- The published data files under `/data/`
- Wrong or misleading sponsorship evidence counts too: report it through the [correction form](https://github.com/ilker-ekin/hadijob/issues/new?template=correction.yml)

Please don't run denial-of-service tests or automated scanners against the site.
